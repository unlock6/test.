# Strategic Investment Intelligence

KIC 전략투자계정 연계 AI 업무에이전트 기획을 반영한 인터랙티브 프론트엔드 프로토타입입니다. 기존 대시보드의 다크 네이비·청록색 디자인을 유지하면서 투자 조사 업무 흐름을 연결했습니다. KIC의 공식 서비스가 아니며 내부 데이터나 시스템을 사용하지 않습니다.

## 실행

`index.html`을 브라우저에서 열면 작동합니다. 지도 데이터가 JavaScript에 포함되어 있어 별도 서버나 빌드가 필요 없습니다. Google Fonts를 사용할 수 없는 환경에서는 시스템 글꼴로 표시됩니다.

## 주요 기능

- 국가·산업·기술·테마별 후보 검색, 조건 저장, 정렬, CSV 내보내기
- 가상 기업 8개, 6개 국가, 4개 산업의 기업 분석과 지도 탐색
- 공급망·기술통제·제재규제·지정학·전략자산 의존·지배구조 위험 분석
- 가중치 공개·조정, 전략적 중요성과 위험을 함께 사용하는 검토 우선도
- 시나리오상 사실·분석적 추론·미확인 정보 구분, 원문 샘플 및 날짜 확인
- 원문 검토 표시와 추가 실사 체크리스트
- 최대 4개 기업 비교
- 자연어 예시를 해석하는 7단계 로컬 업무 시뮬레이션과 실행 중단
- 한국어·영어 검토 보고서 초안, 본문 편집·버전 저장·HTML 내보내기
- 브라우저 인쇄를 통한 PDF 저장
- 수동 샘플 모니터링과 실행 이력, 관심 기업 저장

## 시연

하단 업무에이전트에 다음 요청을 입력하고 **분석 시뮬레이션**을 실행합니다.

> 핵심광물 공급망과 관련된 해외 기업을 찾아 경제안보 위험을 분석해줘

후보 탐색 → 기업 분석 → 위험 스크리닝 → 근거 검증 → 후보 비교 → 보고서 생성 → 모니터링 순으로 진행하며 보고서가 생성됩니다. 요청 해석은 제한된 키워드 규칙을 사용합니다. 지원 범위는 핵심광물·반도체·AI 인프라·에너지와 화면의 국가·기업입니다. 범위를 인식하지 못하거나 결과가 없으면 안내합니다.

## 데이터와 한계

모든 기업·주장·자료·사건·점수는 가상 시나리오입니다. 외부 검증 출처는 0건입니다. 외부 검색·LLM·실시간 뉴스·기관 인증·금융 시스템은 연결되지 않았습니다. 지도에 확인되지 않은 기업 간 공급망 연결선을 그리지 않습니다. 위험 인덱스는 투자 손실 확률, 제재 판정 또는 투자 적격성을 의미하지 않습니다.

브라우저 로컬 저장소에 관심 목록·비교 대상·근거 검토 표시·실사 체크·평가 가중치·보고서 버전·실행 이력을 저장합니다. 다른 브라우저나 기기와 동기화되지 않습니다. 보고서는 생성 시점의 점수와 가중치를 보존합니다.

## 검증

Node.js 18 이상에서 외부 의존성 없이 실행합니다.

```sh
node --check app.js
node --check data.js
node --test tests/smoke.mjs
```

검사는 데이터 일관성, 지도 변환, 검색·정렬·필터, 저장, 비교 개수 제한, 가중치, 업무에이전트 완료·중단, 보고서 필수 항목과 생성 시점 보존을 확인합니다. 로직 검사용 DOM 대체 객체를 사용하므로 실제 브라우저 렌더링·접근성·PDF 레이아웃을 검증하는 테스트는 아닙니다.

## 파일

`index.html` 화면 구조 / `style.css` 반응형 디자인·인쇄 스타일 / `data.js` 가상 시나리오 / `app.js` 상호작용·분석 흐름 / `world-data.js` 내장 세계지도 / `tests/smoke.mjs` 로직 검사.

세계지도는 world-atlas 2의 Natural Earth 기반 countries-110m 자료를 사용했습니다. 기존 `world.json`은 이전 버전과의 호환을 위해 유지되며 새 화면은 `world-data.js`를 사용합니다.
